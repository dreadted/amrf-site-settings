Customize admin panel settings for different user roles.

== Description ==
Admin Panel Settings lets you customize the WordPress admin menu and admin panel options for different user roles. You can hide or show menu items, reorder menus, and fine-tune access to tools and settings.

== Installation ==
1. Upload the `amrf-admin-panel-settings` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to **Settings → Admin Panel Settings** to configure panel settings for each user role.

== Frequently Asked Questions ==
= Can I hide menu items per role? =
Yes. Under the plugin settings, you can select which menu items to hide for each user role.

= How can I reorder admin menu items? =
Use the drag-and-drop interface in the settings page to reorder items as needed.
